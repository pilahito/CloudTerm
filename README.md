# CloudTerm

**Cliente SSH y SFTP.** Escritorio (Windows / Linux) y app nativa Android.
Terminal, gestor de archivos y tus servidores como personajes.

Sin cuenta obligatoria, sin suscripción y sin servidores intermedios: todo se
queda en tu equipo.
