# CloudTerm Android

La app de teléfono es nativa (Kotlin + Compose), no Tauri.
Repo: https://github.com/pilahito/CloudTerm-Android

## Descargar

[CloudTerm-android-1.3.3.apk](https://github.com/pilahito/CloudTerm-Android/releases/download/v1.3.3/CloudTerm-android-1.3.3.apk)

Paquete: `com.pilahito.cloudterm.mobile` (Android 8+).

Si Samsung dice «Aplicación no instalada», desinstala cualquier CloudTerm anterior
y no uses el APK 1.2.0 (era debug).

Escritorio: [v1.0.5](https://github.com/pilahito/CloudTerm/releases/tag/v1.0.5).
